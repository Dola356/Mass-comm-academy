MASSCOMM ACADEMY — ENHANCED PROTOTYPE

HOW TO OPEN
1. Extract this ZIP file.
2. Open the MassComm_Academy_Enhanced folder.
3. Double-click index.html. Use Chrome or Edge.
4. Internet is needed for the optional Google Fonts; the app itself runs locally.

FEATURES INCLUDED
- Responsive dashboard and redesigned navigation.
- Local student profile creation/editing (not secure online authentication).
- Avatar and colour customisation.
- Course library for 100, 200, 300 and 400 levels.
- A general Nigerian Mass Communication course outline, organised by level and semester.
- Starter study notes.
- Multiple-file upload for common image, PDF, Word, PowerPoint, Excel, text and other document formats.
- Browser IndexedDB file storage. Images and PDFs can preview; other Office formats are stored and can be downloaded/opened with a compatible app.
- Practice quiz with marking and explanations.
- Study games: word scramble, flashcards and 60-second quiz.
- Progress tracking: quiz average, questions answered, notes opened, games, activity history and study goal.
- AI assistant preview with selectable personality and answer length.

IMPORTANT LIMITATIONS
This is a browser-based prototype. Profile data and learning progress are saved on this device/browser only. It does not yet have secure account login, password reset, multi-device synchronisation, a shared cloud file library, admin portal or live AI model connection.
The AI assistant currently uses built-in sample answers. A secure backend and AI API integration are required for real open-ended AI responses. Never put a private AI API key in browser JavaScript.
The course outline is a general study framework, not an official syllabus for every university. Course codes, unit loads and semester placement differ. The student's own university handbook and lecturer's outline take priority.
For a production release, the next technical stage is to connect authentication, database and file storage (for example Supabase), set up an admin content dashboard, and connect a live AI service through a secure server function.
